# Ansiktsbehåring, glasögon och halsdukar

Systemet har nu separata Leader Pose-komponenter och katalogtyper för
ansiktsbehåring, glasögon och halsdukar. Kända signalement matchas mot tolv
katalograder. När uppgift saknas renderas ingen accessoar; systemet hittar inte
på skägg, glasögon eller halsduk.

Fyll i `SOURCE_MESHES` i scriptet när kompatibla modulära meshes finns. Kör
sedan scriptet och DataTable-byggaren igen. Katalogen innehåller då totalt 64
systemhanterade rader.
