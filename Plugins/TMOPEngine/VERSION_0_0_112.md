# TMOP Engine 0.0.112

## Player vehicle camera

- Restores the default chase-camera position directly behind the vehicle.
- Mouse look can orbit freely around the vehicle while driving.
- After one second without camera input, the view smoothly returns behind the vehicle.
- Return delay, return speed and default pitch are editable per configured vehicle in Blueprint.
- Existing camera position lag and rotation lag remain active for smoother driving over uneven ground.

No DataTables or historical timelines were changed in this release.
