# TMOPEngine 0.0.126

## Physical-material footsteps

- Seven named surface types: Asphalt, Carpet, Grass, Snow, Stairs, StoneTiles and Wood.
- Independent walk and run sound IDs for every surface.
- Physical material line trace selects the correct ID automatically.
- Audio director supports additional SoundLibrary DataTables without replacing the main library.
- Supplemental `DT_TMOP_FootstepSounds` provides all fourteen editable rows.
