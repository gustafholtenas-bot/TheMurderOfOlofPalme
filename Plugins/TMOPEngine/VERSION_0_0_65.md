# TMOP Engine 0.0.65

## Debug clock-speed shortcuts

- `Shift+3` restores normal simulation-clock speed (`1x`).
- Every press of `Shift+4` doubles the current simulation-clock speed:
  `2x`, `4x`, `8x`, `16x`, `32x`, `64x`, then the clock's safety maximum
  of `100x`.

The Output Log reports the resulting time scale after each shortcut.

Existing shortcuts remain:

- `1` through `9`: 23:00 through 23:40 in five-minute steps.
- `Shift+1`: 30 seconds backwards.
- `Shift+2`: 30 seconds forwards.

Version 0.0.65 includes all fixes and features from version 0.0.64.
